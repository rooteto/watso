## 🚀 Key Features

### 🛒 1. WooCommerce Integration (Your 24/7 Sales Assistant)
* 🛍️ **Contextual Product Assistant**: Pre-filled messages containing product name, URL, SKU, and price.
* 📉 **Checkout & Cart Abandonment Saver**: Reduce cart abandonment rates by placing support buttons directly on Cart and Checkout pages.
* 📦 **Instant Order Status Tracker**: Buyers can ask about their orders directly from the "Thank You" page with Order ID attached.
* 🏷️ **Dynamic Smart Tags**: Use `[product_name]`, `[product_url]`, `[product_price]`, and `[order_id]`.
* 🧠 **Context-Aware Widget**: Dynamically adjusts message template based on current page view.

### 📊 2. Built-in SVG Analytics Dashboard (Data-Driven Growth)
* 🔌 **Zero-Dependency Infrastructure**: Track button clicks without loading any external tracking libraries or slowing down page speed.
* 📈 **Interactive SVG Trend Chart**: Visualize click trends over the last 30 days or all-time history.
* 📅 **Instant AJAX Date Range Filtering**: Switch between Last 30 Days, This Month, Last Month, Last 7 Days, Today, and All Time without page reloads.
* 📊 **Smart Period Comparisons**: Compare current performance against previous periods with instant growth badges.
* 🏆 **Agent Performance Tracking**: Monitor which representative or number receives the most customer clicks.
* 🎯 **Top Converting Pages**: Find out which products or pages generate the most inquiries.
* 🕒 **Peak Hours & Device Breakdown**: Track mobile vs. desktop visitor activity.

### ⚙️ 3. General Settings (Seamless Core Configuration)
* 📍 **Flexible Position Controls**: Bottom-Right, Bottom-Left, Middle-Right, Middle-Left.
* 📱 **Mobile-Specific Toggle**: Choose whether to show or hide on mobile devices.
* 💬 **Custom Menu Header Text**: Write engaging titles for the dropdown menu.

### 🎨 4. Appearance & Branding (Match Your Brand Identity)
* 🖼️ **Custom Icon Uploader**: Replace the default WhatsApp icon with your company logo or custom avatar.
* 🎨 **Harmonious Color Customizer**: Background color, short description, status text, and department colors.
* 📐 **Corner Radius Control**: Modern rounded or classic square corners (0px to 30px).

### 👥 5. Multi-Agent & Department Manager (Structure Your Support)
* 👥 **Unlimited Contact Numbers**: Add unlimited representatives. Single agent redirects directly; multiple agents show a contact menu.
* 🎭 **Custom Avatars & Names**: Set unique titles, custom avatars, and status messages.
* 🏢 **Department Labels**: Organize teams into Sales, Technical Support, Billing, etc.
* 🟢 **Custom Status Messages**: Online, Busy, Away.

### 🎯 6. Advanced Tracking & UTM Parameters (Track Your ROI)
* 🔗 **Auto UTM Builder**: Attach UTM Source, Medium, and Campaign parameters automatically.
* 🎯 **Facebook/Meta Pixel Integration**: Send custom "Watso Contact" events automatically.
* 🌐 **Source URL Tracking**: Include the exact page URL in WhatsApp message text.

### 🕒 7. Smart Time Scheduling (Working Hours Management)
* 📅 **Weekly Working Hours**: Set custom availability times for each day of the week.
* 🏖️ **Holiday Exclusion List**: Define specific holiday dates or company breaks to automatically disable the button.

### 🌍 8. Languages & Localization (Global Reach)
* 🇬🇧 **English** (Default)
* 🇹🇷 **Türkçe** (Turkish)
* 🇫🇷 **Français** (French)
* 🇩🇪 **Deutsch** (German)
* 🇸🇦 **العربية** (Arabic – Fully RTL compatible)

### 🛡️ 9. Privacy & GDPR Compliance
Zero customer data is stored on your server or sent to third parties. All chats happen directly on official WhatsApp platform.

### ⚡ 10. Lightweight & Zero Speed Impact
Built on performance-first guidelines with zero external scripts and zero impact on Google PageSpeed Insights.

## 📦 Installation

1. Upload the plugin files to `/wp-content/plugins/watso-basic-chat/` or install via WordPress plugins directory.
2. Activate the plugin through the **Plugins** screen in WordPress.
3. Use the **Settings > Watso Chat** screen to configure the plugin.
4. Add your WhatsApp number(s) and customize the appearance.
